해당 github에 너가 준 코드를 반영한 후에 일부 서버 코드 에러를 수정해서 업데이트했어.
확인해봐.

2차로 변경이 필요한 부분은 다음과 같아
1) Recipe 관리 탭
- 장비 별 Recipe 현황 테이블에서 Matching Rate 컬럼 포맷팅 수정: 99.~%로 떠야 하는데 0.99%로 뜸

2) Master Recipe 관리 탭
- Model 선택 후 신규 Master 생성 버튼 클릭 시 좌측 기준 정보/우측 Parameter 콤보박스가 KLA2139일때만 아이템이 들어있음
    아마 KLA2139를 제외한 모델은 아직 Master Recipe 등록을 안했기 때문인 듯. 근데 Master만 없는거지 파싱은 다 했기 때문에 수정해야 함.
    Parameter 고유값 리스트를 왜 못 가져왔는지 확인 필요(기준정보는 Master 정보 테이블에 가져오니까 없는게 이해됨)

3) No Master Recipe 조회 탭
- Master Recipe 관리 탭처럼 Model을 선택하도록 상단에 Model 콤보박스 추가
- Model 선택 시 하단 테이블 자동 업데이트

4) 기타
- 불일치 Recipe 조회/집계 제외 Recipe 조회 탭 선택 시 바로 테이블 업데이트 되도록 수정
- README 파일은 한글로! 그리고 서버 운영 명령어도 정리 부탁해
